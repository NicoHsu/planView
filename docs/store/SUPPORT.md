## Troubleshooting

If notifications do not appear:

1. Open iOS Settings.
2. Find PlanView.
3. Enable Notifications.
4. Start a new focus block.

If a timer appears expired:

Open PlanView and complete the reflection. PlanView uses the planned end time to recover sessions after backgrounding or app restart.
