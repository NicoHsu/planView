## Description

PlanView is a local-first timeboxing coach for people who want to make the next hour more concrete.

Instead of managing a huge todo system, PlanView helps you choose one next block, estimate the time, focus, and then quickly record what happened. Each completed block becomes feedback for better planning: which tags take the most time, where estimates drift, and what usually blocks progress.

Use PlanView to:

- Create a Today task pool.
- Add tags and estimated minutes.
- Start a focused timebox in a few taps.
- Pause, resume, or end early.
- Get a local notification when time is up.
- Record whether the block was completed, partially completed, or blocked.
- Track reasons like interruption, underestimated time, or unclear next step.
- Review history and tag-based Plan vs Actual insights.

PlanView works without an account and stores data locally on your device.

## Review Notes

PlanView does not require an account. Core features work offline.

Notifications are used only to remind the user when a planned focus block ends. If notification permission is denied, the app still works and recalculates session status when reopened.

The app does not provide medical advice, diagnosis, therapy, ADHD treatment, or mental health claims.
